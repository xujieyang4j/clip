片段原声
片段动画

动画不改变片段时长。导出时会自动限制到片段有效时长的一半，避免入场和出场重叠。

防抖、倒放、转场和运动动画只在成片预览或导出时完整渲染；强力防抖会增加渲染时间。

画面变换

关键帧以当前片段的成片时间计时，可动画缩放、横移、纵移和不透明度；曲线在相邻关键帧之间生效。

调色
片段特效

暗角和颗粒可叠加到任意调色或片段特效上；普通预览仅作近似显示，以成片预览或导出为准。

视频层（B-roll）

视频层默认铺满画布并静音；它位于主视频上方、文字和贴纸下方。

输出画布

用于黑边填充及旋转后露出的画布区域。

文字 / 字幕

逐字高亮按当前字幕条目的时长均分字符节奏，适合节奏化字幕；不是语音模型逐词时间戳。

画面处理
关键帧动画

关键帧可控制位置、大小和不透明度；曲线定义到下一关键帧的插值。导出与预览共用同一计算规则。

音频

背景音乐会自动循环铺满整条时间线。自动闪避根据主视频原声检测人声/前景声音；响度归一只在最终导出时生效。

独立音频轨

录音会从当前播放头位置插入时间线。首次使用会请求系统麦克风权限。
局部静音

静音区间随音频片段移动，不会改变片段时长。
