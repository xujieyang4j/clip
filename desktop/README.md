# MiniClip 桌面版（Electron + FFmpeg）

MiniClip 是一个可在 **Windows / macOS / Linux** 运行的桌面视频编辑器。当前版本支持多段视频排序、逐片段变速/倒放/调色/推拉，逐边界转场，多画幅画布，文字与本地自动字幕，图片/视频画中画，以及背景音乐混音，最终导出为 MP4。

完整的安装、剪辑和**中英文界面切换**图文说明见：[使用说明](使用说明.md)。

界面预览以响应速度为先，只近似显示部分效果；**FFmpeg 导出的文件才是最终效果的权威结果**。转场、倒放、Ken Burns、模糊背景、libass 字幕、素材淡入淡出和背景音乐混音等，请务必用一次短片导出来确认。

## 一分钟跑起来

前提：安装 [Node.js](https://nodejs.org) 18 或更高版本，建议使用 20 / 22。FFmpeg 无需另行安装，`ffmpeg-static` / `ffprobe-static` 会随依赖准备对应平台的二进制。

```bash
cd desktop
npm install
npm start
```

仓库中的 `desktop/.npmrc` 已配置 npm、Electron 和 electron-builder 国内镜像；`postinstall` 会通过 `scripts/fetch-binaries.js` 检查并补齐 FFmpeg / Electron 二进制。网络中断后可重复执行：

```bash
npm run fetch:binaries
```

启动后点右上角「导入媒体」选择一个或多个视频或图片文件，在下方时间线点选片段，再通过右侧的「片段 / 画布 / 文字 / 叠加 / 音频」面板编辑。图片作为无声主轨片段默认持续 3 秒，可在片段面板修改为 0.1–60 秒；它们可以套用转场、画面变换、特效、字幕和画布设置。完成后点「导出」选择 MP4 保存位置。

编辑过程中可点「保存工程」（或 Ctrl/⌘+S）生成 .miniclip 工程文件；它保存剪辑参数和素材的本机路径，不会复制原视频。需要交付、备份或换电脑继续编辑时，点「打包工程」并选择目标目录：应用会复制所有已引用的视频、图片、音频和 LUT 到独立的 `media/` 目录，并生成路径相对的工程文件。把整个工程包文件夹一起移动即可继续打开编辑。应用还会自动保存一份未命名恢复副本，意外退出后下次启动会尝试恢复；素材被移动或删除时会提示失效数量，恢复原路径后即可继续导出。

打开工程时发现素材路径失效，顶部会出现「重新链接素材」。可逐个选择替代的视频、图片、音频或 LUT 文件；同一失效路径的所有引用会同时更新，时间线、效果、关键帧和字幕不变，视频素材会自动重建编辑代理。

在片段检查器中可使用「在当前播放位置分割」（Ctrl/⌘+B）把选中片段切成两段；原片段的转场会自动保留在右半段与下一片段之间，避免在新切口意外生成转场。

主视频轨支持锁定、**在播放头插入**、覆盖当前片段、波纹删除和原声分离；播放头位于片段中间时插入会自动先分割该片段，插入/覆盖/波纹编辑会同步调整后续字幕、B-roll、叠加、独立音频和时间线标记。主视频、文字、B-roll、叠加和独立音频都支持 Ctrl/⌘+C / Ctrl/⌘+V 在播放头位置复制粘贴。

每个主视频片段都可独立调节原声音量与淡入/淡出；分割会保留两侧片段的音频设置，分离原声时也会把当前音量和淡入淡出带到新建的独立音频轨。

主视频片段支持水平/垂直镜像、旋转和四边裁剪，设置会随工程保存，并同时用于成片预览与最终导出。即时播放器以近似方式显示，旋转后的准确画面以成片预览为准。

主视频还支持 50%–200% 的缩放和横/纵平移：放大时用于重新构图，缩小时或平移出画时会露出所选画布背景色。

除基础调色和 LUT 外，每个片段还可一键应用黑白电影、复古胶片、柔光或锐化特效。特效使用本地 FFmpeg 滤镜实现，能被工程保存、成片预览和最终导出复现；浏览器即时预览为近似效果。

文字和字幕可以选择无衬线、衬线或等宽字体类别，并设置粗体、斜体；这些样式会写入工程，并由 ASS/libass 在成片预览和导出时应用。为提高跨设备稳定性，字体类别依赖系统可用字体或项目随附字体，而不绑定某台机器上的任意字体文件。

文字还可独立调节透明度并与淡入淡出叠加，用于弱化说明文字或制作半透明标题。

文字样式还可调整描边粗细、阴影和字距，用于提升复杂背景上的可读性或制作更醒目的标题。

除顶部、底部、居中等预设位置外，文字/字幕还可用水平和垂直百分比做自由定位；点击“恢复预设位置”即可回到原来的对齐规则。

片段检查器中的「定格」可设置 0.1–30 秒时长；点击「插入定格帧」会取播放头的当前画面，生成本地无声 MP4 并插入时间线。若播放头在片段中间，原片段会自动拆成前后两段；字幕、叠加、视频层和独立音频会随设定时长波纹后移。定格素材也会被「打包工程」一并收集。

音频面板的「录制旁白」会请求一次系统麦克风权限，录音停止后自动以本地 WebM/Ogg 文件保存，并从当前播放头位置插入独立音频轨。旁白与导入音频一样支持时间线裁剪、波形、淡入淡出、基础降噪、人声增强、变速和变调；需要交付工程时使用「打包工程」即可一并收集录音文件。

背景音乐可设置从源文件的指定秒数开始，以及在整条成片上的淡入/淡出；这些设置可与自动闪避、响度归一同时使用。

独立音频轨还支持局部静音：选中音频并把播放头放在需要屏蔽的位置，点击「静音播放头附近 1 秒」即可创建可移除的静音区间。静音区间随片段移动、分割和工程保存，并不会改变片段时长。

时间线上的视频层、叠加、文字和独立音频轨均可分别隐藏/锁定；独立音频轨还可静音。隐藏/静音状态会写入工程，并且影响成片预览和正式导出。

视频层与普通叠加素材均可在检查器中显式上移/下移图层，层级顺序会同时影响即时预览和最终导出。关键帧曲线除预设缓入缓出外，还支持四控制点自定义贝塞尔曲线；工程会保存控制点。

视频层已升级为多个可管理的视频轨：可新建、选择、上下排序、隐藏、锁定和删除空轨；每个视频层可移动到指定轨道。旧工程中的 B-roll 会自动迁移到默认「视频层 1」，轨道顺序决定最终合成层级。

底部时间线按最终成片的真实秒数排布：转场重叠会占用同一时间轴区间。视频、叠加、文字和独立音频显示在各自轨道上；可点击轨道定位、拖动红色播放头，播放时会自动跟随播放头，用右上角 ± 或在鼠标所在位置按 **Ctrl/⌘ + 滚轮** 缩放时间刻度。主视频卡片悬停或选中后会显示左右裁剪柄，也可在右侧检查器的起点/止点滑块裁剪（含倒放和变速片段）；两种方式都会让后续字幕、图层、音频和标记按新的时间线长度同步移动。独立音频、文字和叠加片段也可直接在轨道上选中、拖移、从左右边缘裁剪；临近播放头、0 秒、其他素材边缘或**时间线标记**时会磁吸，并显示青色引导线。按 `M` 可在播放头放置持久化标记，并可在时间线工具栏填写标记注释，`[` / `]` 可跳到前/后标记；标记会随波纹编辑、静音删除和变速曲线同步，并随工程保存。未选中副轨素材时，←/→ 可按工程帧率逐帧移动播放头，Shift+←/→ 按 1 秒跳转；选中副轨素材时方向键微移该素材。选中主视频按 Delete/Backspace 会波纹删除，其他时间线素材则直接删除。视频用 Ctrl/⌘+B 分割；选中独立音频时可在音频面板使用「在播放头处分割音频」（Ctrl/⌘+J）。

片段面板提供帧步进（`,` / `.`）、J/K/L 播放控制、节拍检测与当前片段静音删除。检测后的节拍会以橙色细刻度显示在时间标尺上，并可用于素材磁吸对齐。静音删除会将检测到的静音区间从主轨移除并波纹前移后续素材，建议先保存工程或使用撤销确认效果。

片段面板的「镜头分割」会在本机分析当前保留区间的明显画面切换，并按检测到的镜头切点拆分片段；它不会改变成片总时长，原片段的出场转场仍保留在最后一段。

片段面板还提供单遍「防抖」：标准适合轻微手持抖动，强力会扩大运动搜索并增加渲染耗时。防抖在成片预览和导出中生效；普通播放器预览仍以响应速度优先。

## 可选资源：中文字体与本地字幕模型

这两项都不是启动和普通剪辑的必需条件，且下载命令需要在源码的 `desktop/` 目录执行。

### 中文字体

文字和字幕在导出时由 FFmpeg 的 libass 烧录。未下载项目字体时，libass 会尝试使用系统字体；为减少不同机器上的中文字形差异，可在启动或打包前执行：

```bash
npm run fetch:font
```

命令会把 Noto Sans SC 下载到 `assets/fonts/`，重复执行会跳过已经存在的字体。字体下载失败不会影响依赖安装。

### 本地自动字幕

自动字幕使用可选原生依赖 `smart-whisper` 和 whisper.cpp 的本地 GGML 模型。识别在本机 CPU 上完成；模型准备好后无需把音视频上传到云端。

`smart-whisper` 位于 `optionalDependencies`。通常 `npm install` 会尝试安装；若当前平台的可选依赖被跳过，可手动执行：

```bash
npm install smart-whisper
npm run rebuild:native   # 按 Electron ABI 重建原生模块
```

该模块需要本机原生编译工具：Windows 安装 Visual Studio Build Tools（C++ 工作负载），macOS 安装 Xcode Command Line Tools，Linux 安装 Python 3、make 和 g++。不装它只会禁用自动字幕，不影响其余剪辑与导出。

Whisper 模型体积约 75 MB–1.5 GB，**不会随仓库或安装包分发**。源码运行时可下载默认的 `small` 模型；安装版首次点自动字幕默认下载更轻的 `tiny`：

```bash
npm run fetch:whisper-model
```

也可显式选择模型：

```bash
npm run fetch:whisper-model -- tiny
npm run fetch:whisper-model -- base
npm run fetch:whisper-model -- small
npm run fetch:whisper-model -- medium
```

| 模型 | 典型体积 | 取舍 |
|---|---:|---|
| `tiny` | 约 75 MB | 最小、最快，准确率最低，适合先验证流程 |
| `base` | 约 142 MB | 较快、占用较低，准确率低于 small |
| `small` | 约 466 MB | 默认下载项，中文效果、速度和内存占用较均衡 |
| `medium` | 约 1.5 GB | 通常更准确，但最慢且更占内存 |

源码运行时模型保存在 `assets/models/ggml-<名称>.bin`；安装版首次点「自动字幕」时会从 ModelScope / HuggingFace 镜像下载默认 `tiny` 模型到用户数据目录的 `models/`，之后可离线使用。模型不会塞进安装包。存在多个模型时，会优先使用 `medium`，然后依次是 `small`、`base`、`tiny`。

## 当前编辑能力

### 逐片段编辑

- 每个片段独立设置 **0.25×–4×** 速度，快捷值为 0.5× / 1× / 2× / 4×；导出时画面和原声同步变速。
- 每个片段可独立开启画面与原声倒放。
- Ken Burns 运动支持居中放大和缩小：导出时在 1× 与 1.25× 之间完成一次线性推拉。
- 调色提供「原始、暖色、冷色、鲜艳、黑白」预设，也可手动设置亮度（-0.5–0.5）、对比度（0.5–2）、饱和度（0–3）和色温（-100–100）。
- 片段可跟随画布填充方式，也可单独覆盖为黑边或模糊背景。
- 时间线卡片支持拖动排序、左右移动和删除；片段检查器提供起点/止点裁剪滑块。

### 20 个逐边界切换选项（硬切 + 19 种效果）

每个非末尾片段都可以单独设置「与下一段的转场」，因此不同边界可以使用不同效果和时长。界面提供 20 个选项：

- 硬切；
- 淡入淡出、黑场、白场、溶解；
- 左/右/上/下擦除；
- 左/右/上/下滑动；
- 平滑左、平滑右；
- 圆形展开、圆形闭合、径向、像素化、对角。

转场时长可设为 0–2 秒；导出时还会自动限制为相邻两个片段有效时长中较短者的一半。视频使用 FFmpeg `xfade`，原声使用 `acrossfade` 保持同步。

### 画布与背景

| 画幅 | 输出尺寸 |
|---|---:|
| 16:9 | 1280×720 |
| 9:16 | 720×1280 |
| 1:1 | 720×720 |
| 4:3 | 960×720 |

画布可按比例导出为 720p、1080p、2K 或 4K，并选择 24 / 25 / 30 / 50 / 60 fps；质量预设与分辨率独立，便于先低质量试导、再用同一构图输出高质量成片。默认填充可选黑边或模糊背景，也可指定画布背景色（用于留白与旋转露出的区域）；模糊背景会用铺满画布的模糊副本衬底，并把保持比例的清晰原画居中。

片段调色除基础亮度/对比度/饱和度/色温外，还支持色相、Gamma、两条基础曲线预设和本地 `.cube` / `.3dl` LUT。LUT 是本地文件路径，移动素材后需在工程中重新选择。

### 文字、字幕与 libass

- 手动文字可设置内容、开始/结束时间、7 个位置、12–200 字号、文字色、描边色，以及 0–2 秒的淡入淡出。
- 导出时先生成临时 ASS 文件，再由 FFmpeg `subtitles` 滤镜和 libass 烧录到画面，不依赖 `drawtext`。
- 「自动字幕」识别当前选中的片段；没有选中片段时使用第一段。识别结果会变成普通文字条目，仍可逐条修改内容、时间和样式。
- 「识别全部」会按主视频轨顺序依次转写所有片段，并自动映射到最终时间线；长工程会按片段逐段显示进度。
- 自动字幕只识别片段保留的裁剪区间，并自动把时间映射到变速/倒放后的成片时间线；识别结果仍可逐条校正。
- 支持导入和导出标准 **SRT**：外部校对、翻译后可导回为可编辑文字条目；导出会按时间线顺序生成 SRT。SRT 只交换文字和时间，位置、样式等仍由工程内的文字检查器控制。
- 提供「默认白字 / 白字黄高亮 / 居中大字」批量字幕样式。逐字高亮在 ASS/libass 中实际渲染，但以每条字幕时长均分字符节奏；它适合节奏化字幕，并不表示语音识别模型给出了真实逐词时间戳。
- 字幕检查器支持双语副文本、在播放头拆分、合并下一条和批量查找替换。若本地 Whisper 返回有效 token 时间，逐字高亮会优先按真实 token 时间渲染；无可用 token 时间时才回退为均分字符节奏。双语字幕会以两行写入 ASS 和 SRT。

### 图片/视频叠加（画中画 / 贴纸）

可添加 PNG、JPEG、GIF、WebP、BMP 图片或 MP4、MOV、M4V、MKV、WebM 视频，并设置：

- 在总时间线上的开始/结束时间；
- 大小（界面 5%–100%，按画布宽度缩放）、X/Y 像素位置和不透明度；
- 同一个时长控制的淡入与淡出（0–2 秒）；
- 从当前 X/Y 到目标 X/Y 的匀速线性移动。
- **关键帧动画**：可在任意时间记录位置、大小和不透明度；每段可选线性、缓入、缓出或缓入缓出曲线。预览与导出使用同一套插值。

叠加视频的声音不会加入成片。图片会维持到设定的结束时间；叠加视频如果较短，会静音循环到设定结束时间。

预览画布中选中叠加层后，可直接拖动主体移动、拖右下角控制柄缩放、拖顶部圆形控制柄旋转；旋转也可在检查器中精确调整。若叠加层已有关键帧，画布操作会在当前播放头创建或更新相应的关键帧。

叠加素材还支持左/右/上/下裁剪、水平/垂直镜像、椭圆蒙版、绿幕色键抠像及正常/滤色/正片叠底/线性减淡混合模式。涉及复杂色键、蒙版与混合的最终观感请以成片预览或导出文件为准。

蒙版支持椭圆、圆角矩形、反转和 0–25% 羽化；圆角/反转/羽化使用最终导出的 alpha 通道渲染，即时预览为近似效果。

### 视频层（B-roll）

可将额外视频作为独立的 B-roll 层放在主视频上方。视频层默认覆盖填满画布、静音，可在独立轨道上拖移与裁剪，并设置开始/结束、源起点、循环、不透明度和淡入淡出。最终层级为：主视频 → 视频层 → 文字/画中画/贴纸；视频层的原声音频不会加入成片。

选中视频层后同样可在预览画布中直接拖动、缩放和旋转。

### 背景音乐

支持 MP3、M4A、AAC、WAV、FLAC、OGG。音乐会循环铺满时间线，可分别设置原声和音乐音量，最终由 FFmpeg 混音。

可启用「人声时自动压低背景音乐」，并调整闪避强度：它以主视频原声作为检测信号，在前景声音出现时压低背景音乐。还可启用最终混音的响度归一化（目标 -14 LUFS）；两项均在导出时生效，因此建议用短片先导出试听。

### 独立音频轨

除背景音乐外，还可添加任意数量的独立音频片段。每段可在最终时间线上设置开始/结束、源起点、音量（0–200%）、淡入、淡出以及循环。底部时间线会显示独立音频轨；导出时原声、背景音乐和所有独立音频片段按时间与淡化参数混音。预览仍以视频画面为主，最终音频效果以导出 MP4 为准。

独立音频还支持基础降噪、人声动态增强、速度和音高（±12 半音）独立控制；这些处理使用 FFmpeg 本地滤镜，建议通过「成片预览」或导出短片确认听感。

### 预览边界

预览使用浏览器视频、CSS 滤镜和 HTML 图层快速近似：可以查看顺序、速度、近似调色、文字与叠加素材的位置/移动。它不会完整复现倒放、Ken Burns、逐边界转场、模糊背景、libass 字体与淡入淡出，也不会播放背景音乐混音。

**涉及最终观感和音画同步时，以导出的 MP4 为准。**

需要准确确认时，可点播放器控制条中的「成片预览」。它会渲染一个低码率临时 MP4，使用与正式导出相同的 FFmpeg 图，因此包含转场、字幕、B-roll、图层处理、关键帧和混音；普通浏览器预览仍以响应速度优先。顶部导出预设提供草稿、标准和高质量三档。

普通编辑预览会在后台按需生成 960px 代理媒体，以改善长素材/高码率素材的拖动和播放响应；代理只用于编辑播放，正式导出与成片预览始终使用原素材。

## 打包成安装包

electron-builder 只能可靠地在对应系统上构建对应平台的安装包：

```bash
npm run dist          # 当前平台
npm run dist:mac      # macOS: dmg + zip
npm run dist:win      # Windows: nsis + portable
npm run dist:linux    # Linux: AppImage + deb
```

产物位于 `desktop/dist/`。FFmpeg、ffprobe、`smart-whisper` 原生文件和资源目录按配置从 asar 中解包；`assets/models/*.bin` 明确排除，不会被安装包意外带入。构建时会按目标平台/架构重编译原生语音模块；若希望安装包内固定使用 Noto Sans SC，请先运行 `npm run fetch:font` 再打包。

### 三平台自动打包（GitHub Actions）

仓库的 `.github/workflows/desktop-build.yml` 会在 macOS ARM64、macOS Intel、Windows x64、Ubuntu x64 上并行构建，并以 CPU 后端重建 smart-whisper，避免依赖构建机的 OpenBLAS：

- GitHub 仓库 → Actions → “Desktop Build” → Run workflow：手动构建并从 Artifacts 下载。
- 推送形如 `v1.0.0` 的 tag：自动构建并附加到对应 GitHub Release。

```bash
git tag v1.0.0
git push origin v1.0.0
```

## 代码结构

| 文件 | 作用 |
|---|---|
| `main.js` | Electron 主进程、文件对话框、导出和转写 IPC |
| `preload.js` | 通过 `contextBridge` 暴露受限的渲染进程 API |
| `src/renderer.js` / `timeline-utils.js` | 编辑器状态、时间线、检查器、字幕时间映射和近似预览 |
| `src/ffmpeg-graph.js` | 把片段、转场、画布、调色、叠加和混音编译为 FFmpeg 参数 |
| `src/ffmpeg-runner.js` | 定位 FFmpeg/ffprobe、探测媒体、生成 ASS、执行导出和解析进度 |
| `src/ass-builder.js` | 生成 libass 使用的 ASS 文字/字幕 |
| `src/whisper-runner.js` | 本地音频抽取、smart-whisper 转写和字幕条目转换 |
| `scripts/fetch-binaries.js` | 检查并补齐 Electron / FFmpeg 二进制 |
| `scripts/fetch-font.js` | 可选下载 Noto Sans SC |
| `scripts/fetch-whisper-model.js` | 可选下载 whisper.cpp GGML 模型 |
| `scripts/rebuild-native.js` | 为 Electron ABI 重建 smart-whisper 原生模块 |
| `test/*.test.js` | 纯 Node 单测与真实 FFmpeg 端到端测试 |

导出管线会先按每段设置处理视频和音频，再以 `xfade` / `acrossfade` 或硬切连接片段，随后叠加画中画、用 libass 烧录文字，并混入循环背景音乐。所有时长计算都使用变速后的有效时长。

## 测试

```bash
npm test
npm run test:e2e
npm run test:whisper   # 可选：先准备 tiny 模型，跑真实本地语音识别
```

`npm test` 不需要图形界面，覆盖滤镜图、ASS、进度解析、字幕时间映射、Whisper 纯函数和渲染器启动接线。`npm run test:e2e` 使用随项目准备的 FFmpeg 真实导出，覆盖拼接、转场、变速、倒放、调色、竖屏模糊背景、Ken Burns、叠加素材、字幕与混音。`npm run test:whisper` 使用本地 tiny 模型跑一次真实推理（需要先准备模型）。

## 常见问题

- **`npm install` 卡在下载二进制**：联网后运行 `npm run fetch:binaries`；也可改用官方 npm 源或配置代理。
- **启动提示找不到 FFmpeg**：重新运行 `npm install` / `npm run fetch:binaries`。开发环境还可通过 PATH 中的系统 FFmpeg 兜底。
- **提示缺少 xfade**：当前导出不会自动把已选转场改成硬切。请让项目自带 FFmpeg 生效，或升级系统 FFmpeg；在修复前把各边界设为「硬切」。
- **自动字幕提示缺少引擎**：在 `desktop/` 运行 `npm install smart-whisper && npm run rebuild:native`。它是原生可选依赖，需要系统有 C/C++ 编译工具。
- **自动字幕首次使用较慢**：安装版会先下载默认 tiny 模型（约 75MB）；源码版也可提前运行 `npm run fetch:whisper-model`。模型不会随安装包提供。
- **中文字幕字体不一致或缺字**：运行 `npm run fetch:font` 后重启，再重新导出。
- **预览与成片不同**：这是当前架构的已知边界；预览只是近似，导出的 MP4 才是权威结果。
- **导出较慢**：逐片段效果需要重新编码；默认使用 H.264 `libx264`、CRF 20、preset medium。
